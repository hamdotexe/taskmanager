# Task Manager

A desktop task management (TODO) system for the Software Construction Open-Ended Lab: JavaFX screens over Spring
services. Each task has a title, a description and a status (Pending, In Progress or Completed).

## Requirements

- JDK 25
- Nothing else: the Maven wrapper in this repository downloads Maven and the dependencies on first use.

## Run

```
./mvnw spring-boot:run
```

## Test

```
./mvnw test
```
